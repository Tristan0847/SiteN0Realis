# Architecture du Néant

## Front-end

__**Visuels du site**__
- **[app](../src/Neant/app/)** : Pages et routes Next.js (assemblage UI à partir des components)
- **[components](../src/Neant/components/)** : Composants UI purement visuels récupérant éventuellement des données
- **[lib](../src/Neant/lib/)** : Dépôt de traductions utilisables
- **[public/assets](../src/Neant/public/assets/)** : Images, sons, vidéos, ... contenu statique du site
- **[styles](../src/Neant/styles/)** : CSS, XCSS, ...

__**Moteur de jeu**__
- **[engine](../src/Neant/engine)** : Dossier source du gestionnaire de jeux
  - **[core](../src/Neant/engine/core)** : Briques principales du moteur
    - **[AbstractGameEngine](../src/Neant/engine/core/AbstractGameEngine.ts)** : Moteur principal de jeu, peut et doit être hérité pour avoir des spécifications propres au jeu que l'on souhaite faire (ex: [ShooterGameEngine](../src/Neant/engine/core/ShooterGameEngine.ts))
    - **[entities](../src/Neant/engine/core/entities)** : Gestionnaire des entités du jeu
    - **[scenes](../src/Neant/engine/core/scenes)** : Liste des types de scènes jouables, à faire hériter par des classes concrètes
    - **[ui](../src/Neant/engine/core/ui)** : Éléments d'interface du jeu (boutons, menus, overlays, ...)
    - **[settings](../src/Neant/engine/core/settings)** : Paramétrages du jeu et persistence des paramètres via un singleton
    - **[audio](../src/Neant/engine/core/audio)** : Gestionnaire des bus audios et des musiques de fond
    - **[translations](../src/Neant/engine/core/translations)** : Gestionnaire de traductions du jeu (dépend des paramètres entrés)
    - **[ScenePersistence](../src/Neant/engine/core/ScenePersistence.ts)** : Gestionnaire de sauvegardes du jeu, permet notamment la sauvegarde de la scène courante
  - **[games](../src/Neant/engine/games)** : Liste des jeux utilisant le moteur principal, classes héritantes
  - **[types](../src/Neant/engine/types)** : Types utilisés par le moteur


## Comment utiliser le moteur de jeu ?

1. Commencez par vous placer dans le dossier [games](../src/Neant/engine/games) pour y placer vos créations.
2. **Créer un Engine** : Celui-ci héritera probablement d'une classe héritant déjà d'[AbstractGameEngine](../src/Neant/engine/core/AbstractGameEngine.ts), et ne devrait pas avoir beaucoup d'éléments à initialiser, si ce n'est les fichiers de traductions propres aux jeux.
3. **Créer vos scènes/entités/...** : Dans un sous-dossier **scenes**, créez toutes les scènes qu'il vous faut créer, de même pour les entités ou tout autre éléments dont vous pourriez avoir besoin, qui seraient propre à ce jeu
4. **Créez un Registry de scènes** : Le moteur de jeux a besoin de connaître les scènes instanciables par le jeu, créez donc un simple tableau listant les classes tel que celui ci-desous :
```typescript
export const jpScenes = [
    JPMenuScene, JPShooterScene1, JPShooterScene2, JPShooterScene3, JPShooterScene4, JPShooterScene5, JPShooterScene6, JPShooterScene7, JPShooterScene8, JPShooterScene9, JPShooterScene10,
    JPDialogueScene0, JPDialogueScene1, JPDialogueScene2, JPDialogueScene3, JPDialogueScene4, JPDialogueScene5, JPDialogueScene6, JPDialogueScene7, JPDialogueScene8, JPDialogueScene9, JPDialogueScene10,
    JPShooterEnding, JPShooterFinal1, JPShooterFinal2, JPShooterFinal3, JPShooterFinal4,
] as const;
```
5. Créez le composant qui gèrera l'instance du jeu au complet parmi les [composant roots](../src/Neant/components/roots), exemple :
```tsx
export function JPShooterGameRoot({shooterScenes} : ShooterGameRootProps) {
    const createEngine = (game : Phaser.Game) =>
        new JPGameEngine(
            game,
            {
                initialSceneId: 'jp-dialog-0', // scène initiale de ce shooter
                mainMenuId: "root", // menu principal
            },
            () => setGameEnded(true),
            NeantCookies.jp.currentScene,
        );

    return (
        <BaseGameRoot<ShooterGameState, ShooterSceneEvent>
            createEngine={createEngine}
            scenes={shooterScenes}
        />
    );
}
```
6. **Créez le Loader du jeu** : De même, il faut donc créer un élément qui chargera ce jeu et ces scènes
```tsx
import {JPShooterGameRoot} from "@/components/roots/JPShooterGameRoot";
import {jpScenes} from "./JPSceneRegistry";

export default function JPGameLoader() {
    return <JPShooterGameRoot shooterScenes={jpScenes} />
}
```
7. Il ne vous reste donc qu'à créer la page qui y sera liée, comme dans l'exemple ci-dessous, et votre jeu sera jouable !
```tsx
export default function YEGamePage() {
    return (
        <JPGameLoader />
    )
}
```
